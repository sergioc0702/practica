# Protocolo Valorant - Agentes, Mapas y Armas

Aplicación web interactiva que consulta y presenta información actualizada de agentes, mapas y armas de Valorant consumiendo la API pública de Valorant.

## 🚀 Características

- **Agentes**: Visualización de los agentes, sus roles (Duelista, Centinela, Iniciador, Controlador) y habilidades especiales.
- **Mapas**: Galería y exploración de mapas del juego.
- **Armas**: Listado interactivo de armamento y estadísticas.
- **Diseño Responsivo**: Interfaz moderna con estética inspirada en Valorant.

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Valorant-API** (https://valorant-api.com/)
